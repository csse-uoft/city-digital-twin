# How to Use `removeDockers.sh`

## Overview

This script is used to start Docker containers for the *City Digital Twin* project.

It will:

1. Start the following Docker containers:
   - `city-digital-twin-backend`
   - `city-digital-twin-frontend`
   - `mnt-graphdb-1`
